# password-generator
This is a simple yet effective Password Generator built using HTML, CSS, and JavaScript. It allows users to generate secure passwords of varying lengths. The generated passwords include a combination of:
1. Uppercase letters
2. Lowercase letters
3. Numbers
4. Symbols
 Usage :
1. Open the webpage in a browser.
2. Select the desired password length.
3. Click on the Generate button.
4. Copy your strong, randomly generated password and use it securely.
